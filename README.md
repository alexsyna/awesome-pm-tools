🧰 Awesome PM Tools

Small, free tools for product managers. No sign-up, no backend, nothing to install.

🌐 Live site: https://alexsyna.github.io/awesome-pm-tools/

🎭 TOOL 1: **Clauditorium**: turn any HTML file Claude generates into a link you can share.

🎯 TOOL 2: **Career Fit Scorer**: score and rank job opportunities against your own criteria.

💾 TOOL 3: **Data Anonymizer**: turns a CSV with PII data into a version you can share for research and other purposes, and checks that nobody in it can be identified.

🕵️ TOOL 4: **How Unique Are You?**: a 1-minute game. Pick a few ordinary details about yourself, see how many of Europe's 10 million tech professionals share them, then try to hide in the crowd. Understand k-anonymity.

📄 Apache-2.0. Issues and pull requests welcome.
